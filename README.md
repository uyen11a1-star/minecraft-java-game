# Minecraft Java Game

This repository contains the source code and assets for the Minecraft Java game. It includes modules for gameplay, rendering, and network communication.

## Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/uyen11a1-star/minecraft-java-game.git
   ```
2. Navigate to the project directory:
   ```bash
   cd minecraft-java-game
   ```
3. Build the project using Maven:
   ```bash
   mvn clean install
   ```
